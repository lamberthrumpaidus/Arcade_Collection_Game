## Gambaran umum

Arcade Collection menghimpun 20 permainan browser dengan variasi strategi, logika, refleks, dan mekanik kasual. Katalog menyediakan pencarian, favorit, dan riwayat permainan terakhir.

| Kategori | Contoh |
|---|---|
| Strategi | Tic Tac Toe, Ular Tangga, Sapu Ranjau |
| Aksi dan refleks | Flappy Burung, Dino Lari, Balap Mobil |
| Logika | Cocok Kartu, Tebak Angka, Puzzle |
| Kasual | Ping Pong, Suit Jari, Slot Mesin |

## Teknologi dan struktur

HTML, CSS, dan JavaScript. Halaman utama berada di `index.html`, dengan stylesheet dalam `css/` serta sumber permainan dalam `game_resource/`.

## Menjalankan secara lokal

```bash
git clone https://github.com/lamberthrumpaidus/Arcade_Collection_Game.git
cd Arcade_Collection_Game
python -m http.server 8000
```

Buka `http://localhost:8000/` melalui browser.
